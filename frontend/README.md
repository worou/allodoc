# AlloDoc : front React

Application React 19 (Vite, React Router, TypeScript), installable sur mobile (PWA), avec projet Android (Capacitor) dans `android/`.

```bash
npm install
npm run dev            # http://127.0.0.1:5173
npm run build          # version de production (PWA)
npm run build:android  # build + synchronisation du projet Android
```

Documentation complète (API, connexion, abonnements, application mobile) : voir le [README principal](../README.md).
